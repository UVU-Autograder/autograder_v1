# Documentation Authority Guide

- `JL_AGv1_backlog.md`, `JL_AGv1_decisions.md`, and `JL_AGv1_technical_specs.md` are the canonical Jaxon-authored M1 implementation baseline.
- `JL_AGv1_features.md` and `JL_AGv1_implementation.md` are preserved Jaxon supporting docs that add narrative context and implementation clarifications. When they drift from the first three files, the first three files win.
- `EP_AGV1_backlog.md` and `EP_AGv1_sprint_plan.md` are preserved Easton reference docs copied from `implementation_folder/Implementation_ideas/`.
- When these document families conflict, the Jaxon docs define the active M1 backend, data-retention, hosting, and workflow decisions.
- Easton's preserved docs remain useful for planning context, sprint structure, and historical design rationale, but they are not the implementation source of truth.
