# FERPA unresolved questions

Answered questions have been merged into [ferpa_analysis.md](ferpa_analysis.md). This file tracks only questions that still need UVU, legal, privacy, security, or project-owner confirmation.

## GENERAL ASPECT

1. When does data with names removed still count as a student's education record under FERPA?
2. What requirements must data satisfy before the university considers it anonymous enough?

## DATA STORAGE and SECURITY ASPECT

3. Does a student's code submission count as an education record, even if there is no personal information in the code?
4. At what point does public sandbox activity become an education record?
5. What security controls does the university require for FERPA-covered systems?
6. What are the university's minimum security requirements, including encryption standards, for systems that handle FERPA-protected submissions, grades, logs, exports, or temporary artifacts?

## SANDBOX ASPECT

7. If a student voluntarily or accidentally includes their name or student ID number in code and uploads it to the public sandbox, does that action transform that session into a FERPA-covered record?

## ADMIN ASPECT

8. If the autograder only temporarily processes student submissions and immediately exports results without persistent storage, are there still university retention or audit requirements for processing, logs, AI-generated feedback, or exported grading data?
9. What FERPA expectations exist for instructors, IAs, and system administrators?
10. Is role-based access control sufficient for FERPA compliance?

## AI ASPECT

11. Are AI-generated feedback and comments themselves education records?
