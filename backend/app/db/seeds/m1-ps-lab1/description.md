## **Submit | Festival Ration Preparation - Input, Math, and Formatting**

### **Objective**

Simulate a ration preparation program for a space colony during an annual festival. Citizens receive a fixed ration before distributing special festival supplies.

### 🪐 **Scenario:**

On the planet **Auralis**, the annual *Star Harvest Festival* involves distributing limited food resources. Each colonist receives 4 units of supplies upfront as a fixed ration. The remaining festival stockpile is then used for further strategic allocation.

### **Instruction**

- Prompt the user to enter: - Total number of colonists - Total amount of food supplies (in units)

- Calculate: - Total ration needed: `4 units × number of colonists` - Remaining festival stockpile: `total units - ration amount`

- Print the following outputs: - Original supplies - Total ration allocation - Remaining festival stockpile

### **Sample Input/ Output**

`Enter the number of colonists: 25  `
`Enter the total food units available: 1200  `

`Original supply: 1200  `
`Ration allocation (4 units per colonist): 100  `
`Festival stockpile remaining: 1100  `

### **File Submission**

- Submit your Python file as: `festival_ration.py`
