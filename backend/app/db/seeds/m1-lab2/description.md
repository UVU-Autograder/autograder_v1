## **Submit | Lab | Read Name and Handle, Then Print**

### **Objective**

Write a Python script that prompts the user to enter their **name** and **UVU ID**, then prints a personalized greeting using those values.  Do not use anyone's real UVID for this exercise!

### **Instruction**

- Use the `input()` function to: - Ask the user for their **name** - Ask the user for their **UVU ID**

- Store the values in appropriately named variables.

- Display a message in the format: `"Hello, Alice Smith! Your UVU ID is 12345678."`

### **Sample Input/ Output**

**Input**

`Enter your name: Alice Smith  `
`Enter your UVU ID: 12345678`

**Output**

`Hello, Alice Smith! Your UVU ID is 12345678.`

### **File Submission**

Submit your file as: `greet_user_uvuid.py`

### **Grading Rubrics (10 points)**

- **2 points** - Uses `input()` to collect both name and UVU ID

- **2 points** - Values are stored in appropriately named variables

- **2 points** - Output is clearly formatted and uses both collected values

- **2 point** - Script includes at least one comment explaining a section of the code

- **2 point** - Code runs without syntax errors
