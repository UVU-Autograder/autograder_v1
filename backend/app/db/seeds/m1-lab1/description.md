## **Submit | Sum of Two Numbers**

### **Objective**

Write a Python script that stores two integer values in variables and prints their sum in a clear, formatted message.

### **Instruction**

- Create a Python script that: 1. Defines **two integer variables** with assigned values. 2. **Calculates their sum**. 3. **Prints** the result in the following format: `"The sum of 10 and 20 is 30."`

- 💡 **Optional Challenge:** Modify your script to accept user input using `input()` and handle basic errors (e.g., non-integer input).

### **Sample Input/ Output**

`Enter the first number: 10  `
`Enter the second number: 20  `

`The sum of 10 and 20 is 30.`

### **File Submission**

- Submit your file as: `sum_two_numbers.py`

### **Grading Rubric (10 points)**

- **2 points** - Two integer variables are declared and assigned values correctly

- **2 points** - The sum of the two numbers is correctly calculated

- **2 points** - Output displays a clear and formatted message using `print()`

- **2 point** - Script includes at least one comment explaining a section of the code

- **2 point** - Code runs without any syntax errors
