## **Submit | Basic Arithmetic Function (Add / Sub/ Multi/ Div)**

### **Objective**

Write a Python script that defines a function to perform basic arithmetic operations--addition, subtraction, multiplication, and division--on two numeric values and displays the results in a clear format.

### **Instruction**

- Define a function that takes **two numeric parameters**.

- Inside the function, compute:
  - **Addition**
  - **Subtraction**
  - **Multiplication**
  - **Division** (assume the second number is non-zero for basic functionality).

- Print each result with clear labels and proper formatting.

### **Sample Interaction/ Output**

`Enter the first number: 12  `
`Enter the second number: 5  `
`Enter operation (+, -, *, /, all): all  `

`For inputs 12 and 5:  `
`Addition: 17  `
`Subtraction: 7  `
`Multiplication: 60  `
`Division: 2.4  `

### **File Submission**

Submit your file as: `basic_ops.py`

### **Grading Rubric (10 points)**

- **2 points** - A function is defined that accepts two numeric inputs
- **4 points** - All four operations (add, subtract, multiply, divide) are correctly computed
- **2 points** - Output is clearly formatted and easy to read
- **1 point** - Includes at least one comment or docstring explaining the function
- **1 point** - Code runs without syntax errors
