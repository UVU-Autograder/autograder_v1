## **Submit | Split a List into Even and Odd Numbers**

### **Objective**

Write a Python function that takes a list of integers and returns two new lists--one with even numbers and one with odd numbers--without modifying the original list.

### **Instruction**

1. Define a function that:
   - Accepts a list of integers as a parameter
   - Returns **two new lists**:
     - One containing all **even numbers**
     - One containing all **odd numbers**
   - **Do not mutate the original list**--use list comprehensions or loops to create new ones

2. In your main script:
   - Create a sample list of integers (or prompt the user for integers separated by spaces)
   - Call the function to get the even and odd lists
   - Print the original list, the list of odd values, and the list of even values with clear formatting

### **Sample Input / Output**

**Input:**
```text
Enter integers separated by spaces: 1 2 3 4 5 6 7 8
```

**Output:**
```text
Original list: [1, 2, 3, 4, 5, 6, 7, 8]
Odd values: [1, 3, 5, 7]
Even values: [2, 4, 6, 8]
```

### **File Submission**

Submit your file as: `split_even_odd.py`

### **Grading Rubric (10 points)**

- **2 points** - Defines a function that accepts a list of integers
- **2 points** - Correctly creates a list of odd values
- **2 points** - Correctly creates a list of even values
- **2 points** - Returns both lists and prints them clearly and properly formatted
- **1 point** - Includes at least one comment or docstring explaining the logic
- **1 point** - Code runs without syntax errors
