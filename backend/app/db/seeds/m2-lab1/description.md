## **Submit | Evaluate Equations with Different Parentheses Scopes**

### **Objective**

Write a Python script that demonstrates how the placement of parentheses affects the outcome of mathematical expressions using basic arithmetic operations.

### **Instruction**

- Define **at least three equations** using a mix of addition, subtraction, multiplication, and division.

- For **each equation**, evaluate and display **at least two variations** by changing the placement of parentheses.

- Print both the equation and its evaluated results in a **clear, formatted manner**.

- Include **comments** explaining why the results differ based on parentheses placement.

### **Sample Input/ Output**

`Equation: 2 + 3 * 4  `
`Case 1: 2 + (3 * 4) = 14  `
`Case 2: (2 + 3) * 4 = 20  `

`Equation: 10 - 4 / 2  `
`Case 1: 10 - (4 / 2) = 8.0  `
`Case 2: (10 - 4) / 2 = 3.0  `

### **File Submission**

Submit your file as: `evaluate_equations.py`

### **Grading Rubric (10 points)**

- **3 points** - Defines at least three different equations

- **3 points** - Each equation demonstrates at least two different results using parentheses

- **2 points** - Results are printed in a clear and formatted way

- **1 point** - Includes comments explaining the effect of parentheses

- **1 point** - Code runs without syntax errors
