## **Submit | Count Occurrences of a Character in a String**

### **Objective**

Write a Python function that counts how many times a specific character appears in a given string.

### **Instruction**

- Use string.count() method that accepts one parameter: - A **character** to search for

- This method: - Count how many times the character appears - Return the count

- Store the returned value in a variable and print it in a formatted message.

### **Sample Interaction/ Output**

`Enter a string: APPLE CAT!  `
`Enter a character to count: A  `

**Output:**

`The character 'A' appears 2 time(s) in "APPLE CAT!".`

### **File Submission**

Submit your file as: `count_chars.py`

### **Grading Rubric (10 points)**

- **6 points** - Function returns the count
- **2 points** - Returned value is stored in a variable and printed
- **1 point** - Code includes at least one comment or docstring
- **1 point** - Code runs without syntax errors
