# Part 1: Apply a Photo Filter

It can be fun to apply different effects to photos, such as converting color images to grayscale or black and white. There may be other options, but we’ll stick with these two.

Your task:

1. Choose one of the two filter types listed above. For grayscale, there are two well-known formulas you may use.
2. Modify a copy of `bears.py` to apply your selected filter to `bears_copy.jpg`, and save the result as `bears2.jpg`.
3. Name your modified code file `bears2.py`.

Part 2: Image Compositing

It can be fun to apply different effects to photos, such as mixing one image with another.

Your task:

1. Find an image of a red balloon online.
2. Modify a copy of `bears.py` to add the red balloon into `bears_copy.jpg`. This is done by replacing a section of the bear image with pixels from the balloon image.
3. Save the output image as `bears3.jpg` and your modified code as `bears3.py`.
